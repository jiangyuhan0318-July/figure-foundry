# 图注与数据说明

**图1｜三种虚构模型的合成性能比较。** 所有数据由固定随机种子20261026生成，用于演示科研绘图流程，不代表真实模型、真实数据集或实验结果。Baseline、Variant A、Variant B依次采用用户暖橙组的灰、浅橙、橙色，同时用圆点、方点、菱形区分类别。

**A，学习趋势。** 每组8次模拟运行在21个检查点的分数轨迹；线为运行间均值，带为±1个样本标准差。**B，最终分数。** 每个小标记是一次模拟运行；细线连接相同run_id，黑色短横线和误差线为均值±1标准差。**C，分数与延迟。** 小标记是逐次运行结果，大标记为均值，横、纵误差线分别表示延迟和最终分数的±1标准差。

独立模拟单位为run_id，而不是训练检查点。各面板均来自同一个CSV；没有删除记录、显著性检验、置信区间或真实推理测速。误差条中的SD采用样本公式，分母为n−1。不同方法的同一run_id共享部分生成偏移，以演示配对比较。

| CSV列 | 定义 | 单位 |
|---|---|---|
| method | Baseline、Variant A、Variant B | 类别 |
| run_id | run-01至run-08，方法间配对 | 模拟单位标识 |
| epoch | 0至100，间隔5 | 训练轮次示意 |
| score_pct | 人为设定的饱和曲线及随机偏移/噪声 | 百分比分数，不是实际测量准确率 |
| latency_ms | 人为设定的推理延迟变量，同一运行在检查点间重复记录 | 毫秒示意 |
| data_kind | 固定为synthetic | 来源类型 |

完整数据共504行：3方法×8运行×21检查点。CSV保留计算精度；绘图读取CSV后聚合。原始生成器、绘图入口和机器可读检查结果均随图交付。
